# ════════ 写法示例：每段一个小节，点右边的小节就能对照写法 ════════
# 每行一个小节：和弦 | 简谱 | 歌词 | 伴奏型（后面几栏可以不写）
# 写错了下面会出红字，点红字跳到那一行
# 改动自动保存在你的浏览器里（写谱栏底部会显示）；想存成文件就点「另存为…」

# ════════ 开头设置 ════════
title: 尤克里里写法教程
# artist: 歌手                # 歌手，可不写
key: C                        # 1 = C；换调就改这里
tempo: 80                     # 每分钟 80 拍
time: 4/4                     # 每小节 4 拍
# melody: 0 / instrument: 24    旋律、伴奏音色（默认 10 八音盒、12 马林巴）
# instrument: guitar            换成吉他谱（六线谱），写法见「吉他写法教程」
# 和弦=品位，按 G C E A 四根弦（和弦图从左到右）写；0 空弦，x 不弹，两位数品用逗号
# 常用和弦（C D E F G A Am Dm Em G7 Bm …）不定义也能直接用，这里只写特别的
chord: C高=9,7,8,7 G简=x232
# 伴奏型：D 下扫  U 上扫  X 切音  R 琶音  - 空拍  ~ 延长一拍；时值写法同简谱
pattern p1 = D D_ D__ U__ D D_ D__ U__

# ════════ ① 音符时值 ════════
# 四分 1   八分 1_   十六分 1__   高八度 1'
| 1 2_3_ 4__5__6__7__ 1'      | 四 八 分 十 六 分 音 高

# ════════ ② 八度 · 附点 · 升降 · 休止 ════════
# 低八度 5,   附点 1.   升 #4   降 b7   休止 0
| 5, 1. #4_ b7_ 0_            | 低 附 升 降

# ════════ ③ 延长 · 连音 · 圆滑 · 两段歌词 ════════
# - 延长一拍   ~ 连音（后一个音不唱新字）   ^ 圆滑（两个音各唱各的）   / 分开两段歌词
| 5 - 3_~3_ 2_^1_             | 长 连 圆 滑 / 二 段 歌 词

# ════════ ④ 不配字 · 长休止 ════════
# 这个音不配字：歌词写 -    长休止：0 0
| 6_^5_ 3 0 0                 | 一 - 字

# ════════ ⑤ 和弦 + 扫弦 ════════
# 第 1 栏写和弦（两个就平分一小节），第 4 栏写伴奏型（也可以用 strum: p1 设成后面的默认）
C Am      | 1 2 3 1 | 两 只 老 虎 | p1

# ════════ ⑥ 指定换和弦的拍 · 沿用和弦 ════════
F@1 G@4   | 3 4 5 - | 跑 得 快 | p1     # 第 4 拍换成 G
          | 3 4 5 - | 跑 得 快 | p1     # 第 1 栏空着 = 沿用上一个和弦

# ════════ ⑦ 琶音 · 切音 · 高把位和弦 ════════
C高 G简    | 1 - - - | 啊 | R ~ D_ X_ D_ U_

# ════════ ⑧ 单音「品.弦」（弦 1 = A 最上面，4 = G 最下面）════════
# + 同时弹   x 闷音   h 击/勾弦   s 滑音   t 三连音
C         | | | 0.4_ 0.3+3.1_ x.2_ 0h.2__ 1.2__ 3s.2_ 5.2_ 3.1_t 2.1_t 3.2_t

# ════════ ⑨ 按和弦指弹（谱上画 ×）════════
# *.3 = 按着当前和弦弹第 3 弦；换了和弦，品位自动跟着变
C@1 G@3   | 5 - 3 - | 按 弦 | *.1+*.2+*.4_ *.3_ *.2_ *.1_ *.1+*.2+*.4_ *.3_ *.2_ *.1_

# ════════ ⑩ 只标和弦，先不弹 ════════
F G       | 1 2 3 1 | 两 只 老 虎 | - - - -

# ════════ ⑪ 段落名 · 反复 · 房子 ════════
[副歌]                        # 段落名，标在下一小节上
|:                            # 开始反复
| 1 2 3 4  | 唱 两 遍 的
ending: 1                     # 第一房子：第一遍唱这小节，然后回到 |:
| 5 - - -  | 一
:|                            # 结束反复（:| x3 = 反复三遍）
ending: 2                     # 第二房子：第二遍跳过第一房子，唱这里
| 1' - - - | 二

# ════════ ⑫ 换拍号 ════════
time: 2/4                     # 从下一小节起每小节 2 拍
| 5 5      | 完 了
